# 🎮 Rock Paper Scissors — Python

A beginner-friendly terminal-based Rock Paper Scissors game built using Python.

## ✨ Features
- Colorful terminal interface
- Play against a computer opponent
- Random computer moves
- Live scoreboard
- Multiple rounds and replay support
- Final match result

## 🛠️ Technologies
- Python 3
- `random` module
- `os` module
- ANSI terminal colors

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python rock_paper_scissors.py
```

## 📚 Concepts Practiced
- Conditional statements
- Loops and functions
- Lists and dictionaries
- Random selection
- Basic game logic
